# 🦞 Lobster Squad PWA

龙虾小队 PWA 应用 - 基于 Vite + React + TypeScript + Tailwind CSS

## 技术栈

- **Vite** - 快速构建工具
- **React 18** - UI 框架
- **TypeScript** - 类型安全
- **Tailwind CSS** - 原子化 CSS
- **vite-plugin-pwa** - PWA 支持

## 快速开始

```bash
# 安装依赖
npm install

# 开发模式
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## PWA 功能

- 离线支持
- 可安装到主屏幕
- 自动更新
